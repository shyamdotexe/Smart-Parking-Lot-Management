================================================================================
PART 4 - TEST CLASSES: important members (test code)
================================================================================
All test classes are package-private and use JUnit 5 (@Test, @BeforeEach).
Shared state: ParkingLotCoreTest and ReleaseValidationTest hold a
`ParkingLot parkingLot` field set from ParkingLot.getInstance() then reset()
in @BeforeEach.

Test class -> SUT exercised:
  FirstHourFreePricingTest  -> FirstHourFreePricing
  FlatRatePricingTest       -> FlatRatePricing
  HourlyPricingTest         -> HourlyPricing
  PricingStrategyTest       -> Hourly/Flat/FirstHourFree via Payable (strategy swap)
  ParkingLotCoreTest        -> ParkingLot, Floor, CompactSpot, LargeSpot, Bike, Car, Truck
  ReleaseValidationTest     -> ParkingLot, Floor, CompactSpot, Bike, Car
  ParkingSpotTest           -> ParkingSpot (+ SpotType, PriorityQueue ordering)
  TicketTest                -> Ticket (+ all three pricing strategies, InvalidTicketException)
  VehicleTest               -> Vehicle (+ VehicleType)
