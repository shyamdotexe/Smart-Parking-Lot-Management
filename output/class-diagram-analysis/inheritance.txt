================================================================================
C. SUPERTYPE DESIGN NOTE
================================================================================
- Vehicle IS declared `abstract` but declares NO abstract methods. It cannot be
  instantiated, yet all its methods are concrete. Subclasses only supply a
  VehicleType via the super(...) call.
- ParkingSpot IS declared `abstract` AND declares one abstract method:
      public abstract boolean canFitVehicle(Vehicle vehicle);
  This is the only true abstract method in the project.
